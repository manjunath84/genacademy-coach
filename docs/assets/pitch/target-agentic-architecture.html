Architecture pitch line

GenAcademy Coach is not a single chatbot. It is a grounded learning orchestrator: specialist agents handle teaching, interviewing, diagnosis, planning, memory, and text/voice interaction, while deterministic services control evidence, citations, refusal, grading, privacy, scheduling, and evaluation. The target maps to router, supervisor, and planner-executor patterns while deferring MCP/A2A integrations until earned.
