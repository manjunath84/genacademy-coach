Freedom in the middle. Gates at the edges.

One grounded core — agentic in teaching, deterministic in grounding. If it can't cite the course, it refuses and routes to a mentor.
● shipped & evaluated ◐ Phase-1 build slice (design merged)○ scoped, same core

Gate 1 · Deterministic intake — the model never gets a vote

  1. ● One retrieval per turn, source-prioritized: slides & handouts lead corpus.py · foundation.py
  2. ◐ Strict week/session/source filters — never silently widened
  3. ● Evidence score → band: STOP < 0.40 · CONFIRM 0.40–0.85 · PROCEED > 0.85 grounding.py
  4. ● Citations captured at retrieval — never reconstructed from the answer
▼ band ≥ floor

The teaching brain — the agent's call, logged every turn

  1. ● Teaching move: explain / step-by-step / clarify / quiz / re-explain / refuse+escalate teach_agent.py
  2. ● Explanation lens: low-code · code-heavy · bridge
  3. ● Grounded check-question from a cited span; deterministic grade feeds the next move semantic_grading.py
▼

Gate 2 · Deterministic projection

  1. ◐ Evidence panel = projection of the same retrieval: cited spans by lane + the real slide image — answer and evidence can never disagree
  2. ◐ Next-step chips, corpus-anchored only — never suggest what you'd refuse
  3. ● Trace + eval capture → the dashboard numbers trace.py · eval_runner.py

band = STOP → refusal path ●

Refuse + mentor escalation (review queue) + recovery suggestions ◐ routing back into the course. Refusal is a feature with its own metric — not an error page.
escalation.py

The next-turn loop ●

The deterministic grade updates known[] / struggled[]; the agent observes that and may re-explain differently — analogy, simpler steps, contrastive example. Same question, different learners, different paths. That loop is the autonomy.
