5. Mock Interview is the planned agent lane

One bounded agent adapts questions across turns; rubric scoring and trust gates remain separate, reviewable services.

Planned agent lane
Learner moment
Interview Conductor: Explain why tool-using agents need permission and citation gates.
Because tools let the agent act outside text, so it should retrieve evidence first and check whether the action is allowed.
Feedback: Strong start. Add one concrete tool example, then mention what happens when evidence is missing.

Interview agent move

Chooses the next question from the learner answer and bounded interview state.

Rubric service

Scores cited expected points and cannot reward unsupported model-prior claims.

Gap diagnosis

Labels missing definition, weak contrast, wrong boundary, or an unclear evaluation story.

Feedback output

The lane returns cited feedback and a targeted practice prompt through the same trust gates.

What this proves

Only the adaptive multi-turn interview earns the agent label. Grading, diagnosis, and feedback remain bounded responsibilities.
