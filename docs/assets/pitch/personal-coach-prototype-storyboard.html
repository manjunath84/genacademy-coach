Voice tutor session

Voice turn pipeline

2

3

4

The approved answer appears as text and plays as tutor voice at the same time.

Voice controls

  • Mute and stop always visible.
  • Transcript shown before memory save.
  • Voice output never hides citations; the text answer keeps them visible.
  • Refusal still routes to mentor escalation.

Added risk

Voice can capture sensitive context accidentally. The product needs retention limits, transcript review, and explicit consent before release.

Architecture rule

The voice agent is first-class I/O, not an independent reasoning path. It wraps the same grounded tutor, memory gate, and evaluation trace.

Presenter notes

Core claim

This is not "many agents for optics." Each specialist owns a different cognition: teach, interview, evaluate, diagnose, plan, remember, or speak.
