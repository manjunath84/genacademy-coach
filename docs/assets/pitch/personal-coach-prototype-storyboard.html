What is LangChain, and why would I use it instead of calling an LLM API directly?
LangChain is a framework for composing LLM calls into larger workflows - chaining prompts, tools, memory, and retrieval so you do not wire each step by hand.S1 A direct API call is one prompt in, one completion out; LangChain gives you reusable pieces for multi-step apps like a retrieval-augmented tutor.T1 The handout walks through building exactly that pattern.H1
